# Small raw observation export

The coordinating user requested the underlying measurements, not only classifications. These JSON files copy selected fields directly from locally retained original result files. Every selection records `sourceFile`, SHA256 of the original file, the extraction rule, and unchanged selected values. No result values are synthesized by export.

- KAN-71 baseline: active-window text, browser window IDs, invocation return codes, GET/parent-alive observations for8 trials. Follow-up: real GDK event timestamps, numeric desktop startup timestamps, actual X11 startup ClientMessage observations, before/after active and browser IDs, parent PID, sandbox and local URLs. The two audit trials additionally preserve actual server GET records. Complete startup-ID/token strings were never recorded.
- KAN-90: original two Thunderbird controls and independent real portal result, including actual local GETs, Flatpak instance PID, browser/forkserver snapshots and sandbox preferences. `dbus-events.json` contains the complete small reviewed private-bus trace for SchemeSupported/OpenURI/Response, with only local fixture URLs and message metadata. Request object paths are local DBus handles, not authentication tokens.
- KAN-64: direct native group/member hidden states, workspace transitions/cycles, addon signature/security values and same-extension Firefox hide-all control. Rendering of the retained TST header was visually inspected in the local screenshots; no new sidebar DOM count is fabricated here.
- KAN-20/21: existing records only, no new external network tests. Only exact tested public-page/root navigation status/times, page title/readiness, protection/version metadata, fixture control and response-presence booleans are retained. Cookies, response tokens, page body text, subresources, opaque challenge paths and query strings are omitted. The public demo test-key excerpt is separately identified as a rendering fixture, not real authentication.

Run `python3 ../verify-observations.py` from this directory (or invoke that script by path). It recomputes focus from actual window IDs, checks actual startup messages against launcher timestamps, compares native hidden-tab states, and validates portal response/GET/process continuity. This audits recorded measurements; it does not contact external sites or rerun browsers. Full logs/screenshots/profiles remain outside the repository at `/workspace/qa-linux-22/C`.
