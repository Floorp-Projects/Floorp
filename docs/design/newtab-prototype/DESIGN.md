# 新しいタブのデザイン・操作プロトタイプ

状態: **2026-10-29 に基本仕様・デザインを了承済み**。中央の検索バー、背景と既存機能の継承、半透明表示、入れ子フォルダーを含む最新版を、本体実装の基準とする。製品のデータ連携への実装完了を示すものではない。

製品方針の正本は [新しいタブ・Speed Dial・RSS の製品仕様](../../newtab-speed-dial-rss-spec.md)。本書と食い違う場合は、本チャットで合意した仕様を優先する。元サイトからの本文抽出は、将来も含めて製品仕様に設けない。

本体の責務・保存方式・APIは[設計書](../../newtab-speed-dial-rss/design.md)、工程と受入条件は[実装計画書](../../newtab-speed-dial-rss/implementation-plan.md)を参照。本書は視覚・操作の参照資料とする。

## デザインの基準と優先順位

1. 本チャットで合意した製品方針、現行 Floorp Hub を踏襲しながら使いやすさを保つという指定、および新しいタブの既存機能、特に背景を引き継ぎ、透明化などで美しくするという指定。
2. 現行 Hub の実画面・共通 UI 部品・computed style。アプリの文字、操作部品、余白、狭幅の振る舞いはここに揃える。
3. Web-v5 の現行デザインシステム資料。ブランド、面とレールの意味、文章、アクセシビリティの規則を参照する。
4. 初回の Image Gen 画像とプロトタイプ画像。検討履歴として参照し、現在のデザインの正本にはしない。

Web の全画面 Hero や分割比率をアプリへ機械的に転用しない。左右を分けるのは、選択と詳細など意味のある関係がある場合に限る。独立した情報は一覧・罫線・余白で整理する。Speed Dial のサイトタイルは選択する対象として残す。背景画像があるときは、サイトと新着記事の領域に十分な濃度を持つ白い面を設け、可読性と操作の見つけやすさを確保する。利用者の指定を受け、新しいタブには半透明とぼかしを取り入れる。この機能上必要な面を除き、外側に装飾用カードを重ねない。

## Hub のデザインに合わせる調整方針

- ホームの検索バーは画面の左右中央に配置する。「開発のホーム」などのワークスペース見出しと説明文は表示せず、時計は右上に残す。アクセシビリティ用の「新しいタブ」見出しは画面に表示しない形で保持する。
- ヘッダー左側の正式なロゴを濃紫の面と紫のレールに置き、「ホーム／スピードダイアル／フィード」の横ナビゲーションを維持する。
- 新しいタブの個人背景を維持し、画像の上の操作領域と読む領域には Hub の白・ニュートラルな面を使う。色、書体、余白、境界、選択状態を共通部品・意味別トークンへ揃える。Hub 自体の背景と配色は維持する。ブランドは正式なロゴと公式の単体 PNG をそのまま使う。
- ボタンと入力欄は Hub の共通 Button／Input を再利用する。44pxの操作領域、見えるフォーカス、キーボード操作を保つ。
- RSS は購読先・記事一覧・本文の3領域、17pxの読みやすい本文、狭幅の一覧と本文の切り替えを維持する。配色と操作部品を Hub に合わせる。
- Hub は実装済みのナビゲーション幅、レールの段差、余白、説明列と操作列へ揃える。設定領域は viewport 幅だけで判定せず、現行 Hub と同じ900pxのコンテナ条件で一列へ切り替える。

承認済みの機能構成と画面遷移を保ち、初回プロトタイプで不足していた背景5方式・スライドショー・現在時刻の表示を補う。製品の既存機能の継承と、プロトタイプで確認できる範囲を区別する。

## 既存の背景と時計を引き継ぐ

- 背景なし、内蔵画像からのランダム、自分の画像、フォルダー内の画像、Floorp の画像という現行の5方式を維持する。ランダム／フォルダーではスライドショーの有効化と秒単位の間隔設定を維持する。
- 新規デモの既定は現行と同じランダム背景、スライドショー無効、30秒。製品では利用者が保存済みの種類・画像・ファイル名・フォルダーパス・選択した Floorp 画像・スライドショー設定を引き継ぐ。
- 背景は全画面の中央に `cover` で表示し、切り替え時は1秒でフェードする。動きを減らす設定ではアニメーションを抑える。Hub と専用リーダーには背景画像を重ねず、設定・読書に適した不透明な面を保つ。
- 単体プロトタイプは容量を抑えるため、現行の内蔵画像100枚から3枚を見本として使用する。製品の背景コレクション100枚を減らす方針ではない。Floorp の画像は既存の6枚を使う。
- 時計は現在時刻と地域化された日付を表示し、Hub の表示設定に従う。デモの固定日付で既存の時刻表示を置き換えない。

### 背景を透かす表示

- 背景画像のあるホームと Speed Dial に、白い半透明面と背景のぼかしを適用する。Hub の画面と専用 RSS リーダーは従来の不透明面を維持する。
- サイトの領域は白82%、新着記事は白88%を基本とし、領域ごとに24pxのぼかしをかける。狭幅では16pxへ抑える。各タイルにぼかしを重ねない。
- 文字自体には透明度をかけない。補助文字は `#52525b`、小さい紫のリンクは `#7e22ce` とし、背景が暗くても読み取れる濃度を確保する。
- 写真を一様に暗くせず、時計の背面に濃い減光を残し、下部は壁紙の色を楽しめる明るさにする。面の細い明るい境界と控えめな影で階層を示す。
- Hub の背景設定に「背景を透かす」を設け、従来の不透明表示へ戻せる。既定はデザイン確認用の提案として有効にしている。背景なしでも選択値を保持する。
- ぼかし非対応・透明効果軽減設定では不透明面へ戻す。強制カラーでは壁紙を隠し、システム色の面と境界を用いる。メニューとダイアログは常に不透明にする。

## 画面の役割

| 画面 | 役割と主な操作 |
| --- | --- |
| ホーム | 検索、現在の表示グループの Speed Dial、RSS 新着への入口。記事を選ぶとフィード画面で本文を読む |
| スピードダイアル | ブックマークに連動するグループの閲覧、サイトの追加・編集・並べ替えを確認する画面 |
| フィード | 専用リーダー。購読先、記事一覧、配信された本文を選択・閲覧し、未読・スターを扱う画面 |
| Floorp Hub → 新しいタブ | 新しいタブの表示・見た目・動作を設定する独立した画面 |

ホームとスピードダイアルでは、現在のワークスペースで表示するグループを示す。RSS の購読先・未読・スター、およびスポンサーの掲載内容・表示設定はワークスペース共通とする。

## 閲覧と画面遷移

- 新しいタブのナビゲーションは「ホーム／スピードダイアル／フィード」を基本とする。
- ホームの新着記事を選ぶと、フィード画面へ移り、選択した記事の本文を表示する。
- 広い画面では、購読先・記事一覧・本文を並べ、選択中の購読先と記事が分かるようにする。
- 中間の幅では購読先を収納し、記事一覧と本文に領域を優先する。
- 狭い画面では、記事一覧から本文へ段階的に移る。本文から戻ったときは、一覧の選択とスクロール位置を保持する。
- 全文がフィードで配信されていれば全文、抜粋なら抜粋を表示し、「元サイトで開く」を各記事に用意する。追加の全文取得ボタンは設けない。
- 記事を開いたときに既読にする動作は、初回プロトタイプの操作を引き継ぎ、使い勝手を確認する。

## Speed Dial のグループ

ワークスペースへの**グループ割り当て**は、Hub で保存する初期表示の設定。Speed Dial 画面での**一時的なグループ切り替え**は、現在閲覧するグループの選択であり、割り当てを自動的に上書きしない。

新しいワークスペースは「共通」グループから開始する。同じグループを複数のワークスペースへ割り当てられる。ワークスペースを切り替えても、共通の RSS データやスポンサー設定を初期化しない。

### 入れ子のフォルダー

フォルダーを入れ子にできることはユーザーの指定。以下は、プロトタイプで確認する操作・配置の案とする。

- グループの直下にサイトとフォルダーを並べる。フォルダータイルを選ぶと中へ進み、さらに子フォルダーを作れる。独自の固定の階層数制限を設けず、製品では通常の Places のフォルダー構造へ連動させる。
- 「開発 / リファレンス / フロントエンド」のようなパンくずで現在位置を示す。各祖先へ戻る操作と「一つ上へ」を用意する。狭幅や長い名前でも、画面全体の横溢れや経路の判別不能を避ける。
- サイトの追加・編集時は保存先フォルダーを指定できる。フォルダーには作成・名前変更・移動・削除を用意する。フォルダーを自分自身や子孫へ移動して循環を作る操作を受け付けない。
- フォルダー削除の確認では、その中のサイトと子フォルダーも対象になることと内包する件数を伝える。表示順や削除確認の細かい表現は今回の操作案として検証する。
- ホームはグループ直下の先頭6項目（サイトとフォルダー）を表示する。フォルダータイルは専用 Speed Dial の該当位置を開く。
- ワークスペースやグループを切り替えたときは、新しいグループの入口へ戻す。フォルダーを開くだけで Hub のグループ割り当てを上書きしない。
- スポンサーはフォルダーの子にせず、フォルダー内でも同じ2枠を共通表示する。スポンサーを自分のサイトとして保存するときは、閲覧中のフォルダーを保存先とする。RSS の共通状態は維持する。

## スポンサー枠

- 固定のスポンサー枠は2つ。通常のタイルと同じサイズを基本とし、それぞれに「スポンサー」と明示する。
- ユーザー登録サイトの表示枠とは別に確保する。通常サイトの削除や上書きによって広告を挿入しない。
- 掲載内容は全ワークスペース共通。個別の非表示はタイルのメニュー、2枠全体の表示切り替えは Hub で行う。
- 初期状態は表示を有効にする。利用者による表示の選択は再読み込み後も保持する。
- スポンサーサイトを自分の Speed Dial に追加する操作を用意する。保存されたサイトはユーザー側の登録として扱う。

## Hub の設定構成案

新しいタブの設定ボタンは、Hub の「新しいタブ」ページへの入口とする。新しいタブ内に独立した設定ドロワーやカスタマイズパネルを作らない。

| サブタブ | 設定の分担案 |
| --- | --- |
| 表示とレイアウト | ホームの配置、表示する項目、背景など、新しいタブ全体の見た目 |
| スピードダイアル | 列数・サイズ、ワークスペースとグループの割り当て |
| フィード | RSS の表示・更新などの動作設定 |
| スポンサー | スポンサー枠の一括表示切り替えと、非表示にした項目の復元 |

サイトとフォルダーの作成・編集・移動・並べ替え、購読先の追加、既読・スターといった日常の操作は、Speed Dial／フィード側で行う分担を提案する。

## プロトタイプのデータ

プロトタイプはサンプルデータを用い、操作による表示設定・グループ選択・サイトとフォルダーの階層・記事状態・自分の背景画像などをブラウザーの `localStorage` に保存する。フォルダーから取り込んだ画像は IndexedDB に保存する。製品のブックマーク、Floorp の設定値、RSS のネットワーク取得には未接続である。広告の掲載内容もデモ用データであり、配信サービスへの接続を示すものではない。

プロトタイプのフォルダー選択では、ブラウザーのファイル選択から画像を取り込み、フォルダー名を表示する。製品では既存のネイティブ選択画面とフォルダーパスを用い、画像をフォルダーから参照する。プロトタイプの取り込み方式を製品の保存方式へ置き換える仕様ではない。

記事 URL もデザイン用サンプル。製品実装では各 RSS 項目の実際のリンクを使用する。デモの検索動作は DuckDuckGo を使い、製品では現行と同じく検索欄からブラウザーの URL バーへフォーカスして、URL バー経由で検索・移動する。

既存のブックマーク・背景を含む設定値の製品への移行とブラウザー連携は未実装であり、別途実装・検証する。プロトタイプでの再読み込みによる保持と、実製品の保存・同期の成立は区別する。

## 確認する操作

- ホーム・スピードダイアル・フィード・Hub の間を移動し、戻る先が分かること。
- ワークスペースを切り替えると Speed Dial の割り当てが反映され、RSS の未読・スターが保たれること。
- 一時的なグループ切り替えと Hub の割り当て変更の違いが伝わること。
- フォルダーを複数階層へ入れ子にし、パンくず・一つ上へ・ホームのフォルダータイルから移動できること。
- フォルダーの名前変更、サイトの保存先選択、親フォルダーの変更を確認し、循環する移動が選べないこと。
- フォルダー削除時に中の項目も対象であることが分かり、キャンセルでは階層とサイトが保たれること。
- ワークスペース・グループ切り替えでは入口へ戻り、デモの階層・名前・保存先が再読み込み後も保持されること。
- ホームの記事から本文を開き、一覧へ戻ること。狭い画面でも選択と一覧位置を保てること。
- 全文配信・抜粋配信の本文表示と、元サイトへの入口を確認すること。
- スポンサー2枠の明示、個別非表示、一括切り替え、保存操作を確認すること。
- Hub の変更が新しいタブ側へ反映され、再読み込み後もデモ設定が保持されること。
- 背景5方式、画像選択、フォルダー選択、スライドショーと秒数指定を操作し、設定を切り替えても選択済み画像を失わないこと。
- 背景画像がある場合も文字と操作を読み取りやすく、時計の現在時刻・日付が更新されること。
- サイト未登録、購読未設定、未読ゼロ、取得失敗の状態で、次にできる操作が分かること。
- キーボード操作、フォーカス、長い日本語のサイト名・記事名、狭い画面での折り返しを確認すること。

画像と操作プロトタイプの入口は [README](README.md)、表示比較と操作結果は [REVIEW](REVIEW.md) に記載する。
