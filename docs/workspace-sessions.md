# ワークスペースでログインとブックマークを切り替える

ワークスペース作成時の「ログイン環境」で、作業用のアカウントを使い分けます。

- **現在と共有**: 同じ仕事用アカウントで案件を増やす場合に使います。同じ環境ではログイン・ログアウトも共有します。
- **別のアカウント用に新しく作る**: 新しい通常コンテナを作ります。最初はサイトにログインしていない状態です。
- **既存の環境・標準**: すでに使っているコンテナや、通常の標準環境を選びます。

既定を後から変更すると、新しく開くタブから適用します。既存タブはその環境を維持し、既定と違うタブにはセッション名のバッジが付きます。別ワークスペースへ移す際も、そのまま移動するか、移動先の環境でURLだけを新しく開くかを選べます。新しく開く場合も元タブは残ります。

削除された環境のタブは読み込みを保留します。警告バッジを押し、復旧先の環境を選んでください。別のアカウントで自動的にページを開くことはありません。

## 必要なブックマークだけを表示する

ワークスペースのメニューから「ワークスペースごとのブックマーク表示…」を開くか、ブックマークフォルダーの右クリックから「表示するワークスペース…」を選びます。

フォルダーは複数のワークスペースに表示できます。親にも制限があれば、親と子の両方で許可した場所だけに表示されます。設定していないフォルダーは親に従い、制限のない場所では共通表示です。表示先がなくなっても、ブックマーク自体は削除されません。

星マークの編集画面には「このワークスペース用に保存」があります。同じURLを複数の場所に保存している場合は、編集するブックマークを選べます。全ブックマークの管理画面では、表示先にかかわらず全件を確認できます。

ブックマーク自体は通常どおり同期します。表示先の設定は端末内に保存します。設定画面からバックアップでき、別の環境への復元時にはフォルダー・ワークスペースを明示的に対応付け、変更内容を確認して適用します。

## スワイプとショートカット

ワークスペースのメニューから「ワークスペースの切り替え」を開くと、サイドバー内の水平スワイプを有効にできます。初期状態はオフです。ページ内のスクロール操作には適用しません。

ショートカットやマウスジェスチャーの設定には「次のワークスペース（端で停止）」「前のワークスペース（端で停止）」を追加しています。OSが3本指操作をキー入力へ変換できる場合は、これらのアクションへ割り当てられます。OS側では1回の操作で1回だけキーを送るように設定してください。

直接3本指入力はGTK向けの試験実装です。対応Runtimeのビルドと実機検証が必要で、未検証の環境では選択できません。macOS・Windowsの直接3本指入力は未対応です。詳しくは[対応表と検証手順](workspace-native-input.md)を参照してください。

## 分かれる情報と共有する情報

Cookie・サイトストレージは選んだログイン環境ごとに分かれます。同じ環境を共有するワークスペース同士では共有します。

保存済みパスワード、閲覧履歴、拡張機能は同じプロファイル内で共有します。ブックマークの表示先は整理のための設定で、URLへのアクセス制限ではありません。履歴や拡張機能などでは同じURLが表示されることがあります。
